= Building Greybus

== Adding Greybus to Zephyr

To pull Greybus for Zephyr in as a Zephyr module, either add it as a West project
in `west.yaml` or include it via a submanifest file (for example,
`zephyr/submanifests/greybus.yaml`) with the following content, then run
`west update`:

[source,yaml]
----
manifest:
  projects:
    - name: Greybus-Zephyr
      path: modules/lib/greybus
      revision: main
      url: https://github.com/beagleboard/greybus-zephyr
----

== Building an Application

Greybus is enabled with `CONFIG_GREYBUS=y`, and starts automatically during
`SYS_INIT` unless `CONFIG_GREYBUS_SERVICE` is disabled. Beyond that, an
application needs to select a transport and describe the peripherals it exposes
in devicetree. `samples/basic` is a complete, minimal example of both.

For a board-specific walkthrough covering transport selection, MCUboot, and
programming a device, see xref:beagleconnect-freedom.adoc[].
